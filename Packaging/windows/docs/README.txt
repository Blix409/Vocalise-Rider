VOCALISE-RIDER
A free automatic vocal level rider by Daemonj Multimedia.

It listens to a vocal and moves the volume up and down for you, like riding a fader by hand. It only changes
volume, never tone, so the sound stays clean. Set how loud the loud parts and how quiet the quiet parts can get,
then let it ride. Use WRITE mode to record the ride as automation in your DAW, or use it live.

Format: VST3 (64-bit Windows). Works in Reaper, Cubase, Studio One, Ableton Live, FL Studio and other VST3 hosts.
Click the "?" icon in the plugin for a guide to every control (also in HOW-TO-USE.txt).
Click the gear icon for the About panel.
