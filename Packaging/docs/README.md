# Vocalise-Rider

**A free automatic vocal level rider by Daemonj Multimedia.**

It listens to a vocal and moves the volume up and down for you, like riding a fader by hand. It only changes
volume, never tone, so the sound stays clean. Set how loud the loud parts and how quiet the quiet parts can get (the Tame Peaks and Lower Levels lines),
then let it ride. Use WRITE mode to record the ride as Logic automation, or use it live.

- Formats: Audio Unit (Logic Pro, GarageBand and other AU hosts), VST3 (Reaper, Cubase, Studio One, Ableton Live, FL Studio and others)
- Runs natively on Intel and Apple Silicon Macs
- Click the **?** icon in the plugin for a guide to every control (also in HOW-TO-USE.md)
- Click the gear icon for the About panel
