Before you install

  • Close Logic Pro (or your DAW) first. Restart it after the install.
  • You will be asked for your Mac password. Plugins are installed for every user in /Library/Audio/Plug-Ins/.
  • The installer also clears macOS's "downloaded from the internet" flag from the plugin, so your DAW can load it. It does not change any security setting on your Mac.
  • Click Customize on the next step to pick which plugin formats to install.
  • The guides (README, install help, how to use) are always installed to /Users/Shared/Daemonj Multimedia/Vocalise-Rider/Documents.

In Logic: Audio FX > Audio Units > Daemonj Multimedia > Vocalise-Rider. Click the ? icon in the plugin for a guide to every control.
